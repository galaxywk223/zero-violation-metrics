# Claim Flow

The table records the paper-level chain from evaluation object to claim boundary.

| stage | component | content | paper role |
| --- | ---: | ---: | ---: |
| 1 | Evaluation object | Episode return and cost sequence define both reward and violation events. | Establishes the measurement target. |
| 2 | Metric families | Expected cost, safe rate, tail severity, and temporal persistence answer different questions. | Prevents collapsing safety into one scalar. |
| 3 | Baseline matrix | Six mature methods across three environments and three seeds expose the reward-safety landscape. | Provides the empirical substrate. |
| 4 | Supported claims | Metric non-equivalence, no true zero violation among evaluated baselines, and FOCOPS as balanced comparator. | Defines what the paper can claim. |
| 5 | Claim boundary | The study is not a universal failure theorem and not a new-method success result. | Protects the conclusion from overstatement. |
